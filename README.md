# SUSHI HOUSE — v18 Dark Tokyo / House Mix

Design iteration based on SKELETON v1 and v17 Tokyo Premium.

## Direction
- Fully dark visual system; no cream/white content sections.
- Tokyo premium hero/header language remains.
- Menu uses varied dark card treatments instead of making every section identical.
- Red is reserved for primary actions and selected states.
- White is used only for text/contrast, not as a section background.
- Mobile 2-column category/subcategory grid is preserved.
- Product quantity controls and cart logic are preserved.
- Fixed text overlap in category/subcategory cards.

## Safety
SKELETON v1 remains the rollback baseline. This is a separate design iteration.
