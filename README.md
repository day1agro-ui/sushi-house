# SUSHI HOUSE — MVP

Первый рабочий прототип сайта по концепции «Шабашка».

## Запуск

Откройте `index.html` в браузере. Сервер не требуется.

## Уже работает
- адаптивная главная страница;
- категории меню;
- фильтрация товаров;
- карточки блюд;
- корзина;
- подсчёт суммы;
- мобильное меню;
- CTA «Заказать».
